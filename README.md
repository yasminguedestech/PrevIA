# PrevIA
*Repositório para o PBL da Fiap - PrevIA*

Sobre o projeto

O PreviA é um aplicativo que cruza a previsão do tempo com o histórico e o estado atual do tráfego de ônibus, trens e metrô de São Paulo. Com isso, calcula a probabilidade de atraso de cada linha e avisa o usuário com antecedência, para que ele planeje a saída com mais segurança.

Principais ideias:
Cruzar dados meteorológicos (OpenWeather/INMET) com dados de transporte (SPTrans Olho Vivo, ARTESP API Trilhos).
Calcular um fator de atraso por linha, considerando pontos históricos de alagamento, volume de chuva previsto e lentidão viária.
Permitir projeções para horários futuros e alertas preventivos sobre as linhas escolhidas pelo usuário.
Exibir no mapa as zonas de risco climático (integração com o CGE-SP).
Respeitar a privacidade: sem rastreamento contínuo por GPS (LGPD).
